## Free GitHub Pages deployment
1. Create a GitHub repository such as `sharad-portfolio`.
2. Upload all files in this folder to the repository root.
3. GitHub → repository Settings → Pages.
4. Choose "Deploy from a branch", branch `main`, folder `/ (root)`.
5. Save. GitHub will provide your public portfolio URL.
6. Add that URL to LinkedIn under Contact Info and Featured.

Tip: Keep the repository public if you want GitHub Pages to be easy to share.
